Connect to the ESP32 for live status

This public page is a presentation demo and cannot directly read an ESP32 on your local network. The device dashboard is served locally by the firmware. Upload the current firmware, then connect your phone/computer to the device setup Wi-Fi.

01 · FLASHFrom the project directory run pio run -e esp32dev --target upload.
02 · CONNECTOpen serial monitor at 115200 baud; join the printed SetuNet-Setup-XXXX network.
03 · OPENBrowse to http://192.168.4.1 for the live local dashboard.
